# nextgen design V5 — professional developer direction

This iteration changes the visual language instead of simply restyling V4.

## Direction

- Technical/editorial rather than SaaS landing page
- Restrained section headings (roughly 32–42px)
- Strong but compact hero
- Monospace used only for metadata, versions and technical labels
- Subtle engineering grid, not decorative blobs
- Real project/version/status information used as visual content
- phpBB themes treated as maintained software projects
- Dark engineering-principles section used once for contrast
- Smaller radii, lighter shadows and more deliberate borders
- Cleaner header with GitHub and project CTA
- Improved responsive behavior

## Files

Replace these files in your existing Next.js project:

- `app/page.tsx`
- `app/globals.css`
- `components/Header.tsx`
- `components/Footer.tsx`
- `components/ProjectCard.tsx`

The existing `public/assets` folder is untouched.
