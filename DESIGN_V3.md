# Design V3 — refined type scale

This patch keeps the V2 visual direction but makes the hierarchy more restrained.

## Main changes
- Section `h2` titles are intentionally moderate rather than oversized.
- Desktop section titles top out around 52px.
- Mobile section titles top out around 42px.
- Featured extension and CTA headings use their own restrained scale.
- Cards are shorter and slightly less rounded.
- Vertical section spacing is tighter.
- Service headings are smaller and easier to scan.
- The hero remains the primary large typographic moment.

Replace `app/globals.css` in your current Next.js project with the file from this patch, restart the dev server, then hard-refresh the browser.
